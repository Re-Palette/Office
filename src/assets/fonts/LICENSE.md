# Noto Sans JP — SIL Open Font License 1.1

`NotoSansJP-Regular.ttf` / `NotoSansJP-Bold.ttf` in this directory are **subsets**
of Google's Noto Sans JP, reduced to JIS X 0208 (6,879 codepoints) plus Latin,
punctuation and symbol ranges — 8,099 glyphs each, ~2.3 MB per weight instead of
~5.3 MB. They are embedded (subset again, per document) into the PDFs generated
by `/reports/[id]/pdf`, so Japanese text renders correctly in any PDF viewer
without relying on fonts installed on the reader's machine.
